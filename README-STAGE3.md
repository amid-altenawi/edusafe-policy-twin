# EduSafe Policy Twin — Stage 3 installation (Arabic)

## الهدف

إضافة واجهة تفاعلية ثنائية اللغة (إنجليزية/عربية) إلى مشروعك الحالي، وتحسين الصفحة التعريفية README.md. الواجهة تقرأ محرك المحاكاة ومكتبة الأدلة الموجودين في المشروع نفسه؛ لا تتصل بآلة حقيقية ولا تتطلب حسابًا جديدًا.

## التثبيت على Windows

1. نزّل ملف `edusafe-stage3.zip` وافتحه بواسطة **Extract All**.
2. افتح المجلد المستخرج، وانسخ المجلد `demo` والملف `README.md` والملف `tests/demo_ui.test.mjs` إلى مشروعك في:

   `C:\Users\ASUS\edusafe-policy-twin`

3. عندما يسألك Windows عن استبدال `README.md` وافق. هذا استبدال مقصود للوصف الافتراضي؛ الإصدار السابق محفوظ في Git.
4. **لا تحذف** مجلد `tests` القديم. أضف إليه ملف `demo_ui.test.mjs` مع الإبقاء على الاختبارات السابقة.

## اختبار المرحلة الثالثة

في نافذة CMD، نفّذ كل أمر لوحده واضغط Enter بعده.

```cmd
cd /d "C:\Users\ASUS\edusafe-policy-twin"
```

ثم:

```cmd
node --test tests\demo_ui.test.mjs
```

ينبغي أن تظهر 5 اختبارات ناجحة؛ إذا ظهر خطأ، أرسل نتيجته قبل متابعة التنفيذ.

## تشغيل الواجهة

```cmd
node demo\server.mjs
```

ثم افتح من المتصفح:

**http://127.0.0.1:4173**

سترى لوحة EduSafe التفاعلية. جرّب:

- زر **Reset** ثم **Next event** خمس مرات.
- زر **Run all**.
- خيار **No supervisor intervention** (سيتوقف تقييم الخطر عند CRITICAL).
- زر **العربية**.
- زر **Export audit JSON** لتنزيل سجل محاكاة تجريبي.

لإيقاف الخادم المحلي ارجع إلى نافذة CMD التي تشغل الواجهة واضغط **Ctrl+C**.

## بعد التأكد من نجاح التشغيل

لا ترفع أو تنشر ملفات إضافية قبل التأكد من أن الاختبارات والواجهة يعملان. بعد النجاح يمكن حفظ المرحلة الجديدة في Git ثم إرسالها إلى المستودع الخاص. سأعطيك الأوامر واحدًا واحدًا.

## حدود مهمة

- يعمل محليًا فقط، وليس موقعًا منشورًا على الإنترنت.
- لا توجد بيانات حساسات أو قراءات آلة حقيقية.
- مصادر الأدلة بيانات مرجعية محفوظة، وليست استرجاعًا مباشرًا من المواقع وقت التشغيل.
- لا يمثّل شهادة امتثال قانونية أو سلامة معتمدة.
